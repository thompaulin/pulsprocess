# Site Pulse 2027

Site statique prêt pour GitHub + Vercel.

## Mise en ligne

1. Dézipper le fichier.
2. Envoyer tous les fichiers à la racine du dépôt GitHub.
3. Ne pas envoyer le ZIP dans le dépôt.
4. Vercel redéploie automatiquement.

## Fichiers principaux

- index.html
- sonorisation.html
- lumieres.html
- extras.html
- realisations.html
- process.html
- contact.html
- mentions-legales.html
- styles.css
- script.js

Tous les assets sont à la racine pour faciliter l'import manuel dans GitHub.
